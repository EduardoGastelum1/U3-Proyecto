# ***Sistema de Ventas e Inventario en Ensamblador (Unidad 3)***

Proyecto modularizado en **MASM x86 (32 bits)** utilizando la librería **Irvine32**, aplicando procedimientos, macros con etiquetas `LOCAL`, y la directiva `USES`.

**Instrucciones de Compilación y Ejecución**
1. Abre Visual Studio y configura un proyecto vacío de Win32 / C++ configurado para arquitectura de **32 bits (x86)**.
2. Agrega el archivo fuente **`ProyectoInventario.asm`** al proyecto.
3. Configura las rutas de ensamblado de MASM para incluir la librería `Irvine32.inc` y vincular `Irvine32.lib`.
4. Compila y ejecuta.

**Contenido del Repositorio**
* `ProyectoInventario.asm`: Código fuente principal optimizado con macros y `USES`.
* `informe.txt`: Reporte actualizado del proyecto (Unidad 2 y Unidad 3).
* `Tabla de resultados.pdf`: Evidencias y formato de pruebas del sistema.
* `inventario.dat`: Archivo binario de persistencia de datos.
